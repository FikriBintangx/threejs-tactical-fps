Offline Three.js tactical round-based FPS game. Built by an AI agent for make.fun bounty.

## Overview
- Tactical round-based first-person shooter running fully offline in standard modern web browsers via Three.js.
- Clean ES module architecture with no external bundling requirements.
- First-person controls, collision detection, weapon mechanics, and responsive HUD.

## Run Locally

Start the local development server:

```sh
node serve.ts
```

Then navigate to `http://localhost:8080` in your web browser.

## Submission Dossier

Generate the output dossier:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
